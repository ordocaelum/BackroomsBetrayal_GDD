# Backrooms: Betrayal — Game Design Document

A polished, single-page HTML game design document and roadmap tracker for **Backrooms: Betrayal** — a cooperative multiplayer liminal horror game about maintaining reality within unstable Backrooms sectors.

## Viewing

Open `index.html` in any modern browser. No build step or server required.

```
open index.html
```

Or serve locally with any static server:

```
npx serve .
python3 -m http.server
```

## Structure

```
BackroomsBetrayal_GDD/
```
